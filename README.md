# 📚 Estudo – Programação Distribuída e Paralela

Site interativo de estudo para a prova de **Programação Distribuída e Paralela**.

🔗 **Acesse:** https://luan-k10.github.io/estudo-programacao-distribuida/

## O que tem
- **Resumos** de todos os temas: princípios de sistemas distribuídos, threads e async/await, comunicação entre sistemas, arquiteturas/middleware, semáforos e mutex, Monitor, ManualResetEvent/AutoResetEvent.
- **Quiz** com correção e explicação imediatas (Lista 1 + 100+ questões extras, filtro por tema, revisão das erradas).
- **Simulado** cronometrado com nota final e correção.
- **Flashcards** (Espaço vira, ← → navega).
- **Discursivas** com resposta-modelo e pontos-chave.
- **Laboratório** com simulações: race condition, semáforo/mutex, Manual vs AutoResetEvent, síncrono vs assíncrono e deadlock.

O progresso fica salvo no navegador (localStorage). Site estático: basta abrir o `index.html`.
